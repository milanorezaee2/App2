# وضعیت کنترل گوشی و اشتراک صفحه

قابلیت جفت‌سازی گوشی، گزارش موقعیت/دستگاه، کنترل لمسی و اشتراک زندهٔ صفحه از APKهای آموزشی و مدیریتی پاک‌سازی‌شده حذف شده است. این بسته‌ها سرویس دسترس‌پذیری یا سرویس MediaProjection را نصب نمی‌کنند و مجوزهای مربوط به کنترل گوشی، مکان و نمایش روی برنامه‌های دیگر را درخواست نمی‌کنند.

محتوای درس‌ها، پیشرفت آموزشی، تلفظ، اعلان‌های چت و تماس صوتی داخل گفتگوها حفظ شده‌اند.

فایل‌ها و جدول‌های SQL قدیمی مربوط به دستگاه در مخزن/پروژهٔ Supabase حذف یا اجرا نشده‌اند؛ این تغییر فقط برنامه‌های Android را پاک‌سازی می‌کند و داده‌های قبلی سرور را دست‌کاری نمی‌کند. راهنمای قدیمی این سند دیگر برای APKهای جدید کاربرد ندارد.
