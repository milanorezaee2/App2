## نصب روی گوشی اندروید

1. لینک را در مرورگر گوشی باز کنید و فایل را دانلود کنید.
2. اگر پیام «نصب از منابع ناشناس» آمد، برای همان مرورگر اجازه بدهید.
3. فایل را باز کنید و **Install** را بزنید. اگر نسخهٔ قبلی نصب است، روی آن آپدیت می‌شود.
4. اگر Play Protect هشدار داد (چون با کلید دیباگ امضا شده)، «Install anyway» را بزنید.

> هر سه فایل را هم‌زمان نصب نکنید: `MiloMultilang.apk` و `MiloMultilang-Login.apk`
> بستهٔ یکسانی دارند و روی هم بازنویسی می‌شوند. یکی را انتخاب کنید.

## چه چیزی در این نسخه عوض شده

**۱) بخش روسی حالا یک نریتور زن دارد که داخل خود برنامه است**

- تا نسخهٔ قبل، جمله‌های روسی با هر صدای `ru-RU` که گوشی داشت خوانده می‌شد؛ روی
  خیلی از گوشی‌ها چنین صدایی نصب نیست (یا مردانه و مصنوعی است) و فایرفاکس اندروید
  اصلاً موتور گفتار ندارد.
- از این نسخه، **۱۳۸ کلیپ آماده** (هر ۶۹ درس و همهٔ واژه‌ها) با یک گویندهٔ زن عصبی
  (`ru_RU-irina-medium`، خانوادهٔ Piper/VITS) داخل اپ است. صدا آرام، مهربان و شیوا
  است و با همان پردازش «گرم» صدای آلمانی ساخته شده تا هر دو دوره یک جنس داشته باشند.
- سرعت: **۱۴۷ کلمه در دقیقه** (اندازه‌گیری‌شده از خود کلیپ‌های ارسالی؛ نزدیک به
  گوینده‌های آلمانی که ۱۴۱ تا ۱۵۱ هستند).

**۲) محتوا، ساختار و چیدمان روسی دست‌نخورده است**

- هیچ جمله، واژه، ترجمه، تمرین، مرحلهٔ درس (همان ۹ مرحله) و هیچ صفحه‌ای عوض نشد.
- فقط منبع صدا عوض شد: خانهٔ روسی، درس روسی و مرور روسی حالا از بستهٔ داخلی
  می‌خوانند. دکمه‌ها، متن‌ها و پیام‌های خطا همان‌اند.
- صدای خود گوشی **حذف نشده**؛ فقط دیگر انتخاب اول نیست. اگر پخش یک کلیپ به‌کلی
  شکست بخورد، همان یک جمله با صدای روسی گوشی خوانده می‌شود تا درس بی‌صدا نماند.

**۳) هیچ جمله یا واژه‌ای با جملهٔ قبلی/بعدی قاطی نمی‌شود**

- هر جمله و هر واژه جداگانه ساخته می‌شود و **۰٫۳ ثانیه سکوت کامل قبل** و
  **۰٫۵۵ ثانیه (واژه‌ها ۰٫۴۵) سکوت کامل بعد** آن گذاشته می‌شود.
- پخش‌کننده ۰٫۲۵ ثانیه قبل از شروع گفتار شروع می‌کند و ۰٫۱۵ ثانیه بعد از پایان آن
  تمام می‌کند؛ یعنی همیشه داخل سکوت. سازندهٔ بسته اگر سکوت اطراف کلیپ‌ها واقعاً
  سکوت نباشد اجازهٔ ساخت نمی‌دهد.
- علامت تکیه که در متن درس روی واکه‌هاست (`Приве́т!`) برای خواندن حذف می‌شود،
  ولی متن نمایش‌داده‌شده به زبان‌آموز همان متن قبلی است.

**۴) بقیهٔ چیزها دست‌نخورده**

- آلمانی با همان سه گوینده و انتخاب کاربر کار می‌کند (۵۷۰ کلیپ). انگلیسی مثل قبل.
- آیکون بلندگو در درس آلمانی: لمس اول آهسته، لمس دوم معمولی.
- صفحهٔ شروع همان ۱٫۲ ثانیه است.

## بازسازی

```bash
git push origin arena/76e3f058-app2   # ورک‌فلوی .github/workflows/apk-quick.yml
```

برای تغییر گوینده یا سرعت روسی:

```bash
node scripts/fetch-russian-voice-model.cjs            # مدل ۶۳ مگابایتی (یک‌بار)
python3 -m venv .venv-audio
.venv-audio/bin/pip install piper-tts onnxruntime numpy scipy lameenc
node scripts/export-russian-course.cjs
.venv-audio/bin/python scripts/generate-russian-audio.py
.venv-audio/bin/python scripts/generate-russian-audio.py --refresh-labels
node scripts/generate-russian-audio-assets.cjs
```

گوینده، سرعت و پیش‌فرض فقط در `config/russian-narrator.json` است؛ برای نمونه‌گرفتن
`scripts/preview-russian-voice.py` را اجرا کنید.
