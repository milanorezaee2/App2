# راه‌اندازی صدای انسانی نریتور در Supabase — قدم‌به‌قدم و ساده

هدف: صدای نریتور درس‌ها (انگلیسی، آلمانی، روسی) از «صدای دستگاه» به **صدای
انسانی و طبیعی** تبدیل شود. کل کار حدود **۱۰ دقیقه** است و **یک‌بار** انجام
می‌شود. به بیلد جدید اپ هم نیازی نیست.

دو مسیر دارید؛ هرکدام راحت‌تر بود انتخاب کنید:

- **مسیر الف — فقط با مرورگر (بدون ترمینال)**: از داشبورد Supabase.
- **مسیر ب — با ترمینال**: سه فرمان آماده.

---

## مسیر الف) فقط با مرورگر

### قدم ۱ — گرفتن کلید صدا (یکی از دو گزینه)

**گزینهٔ ۱: ElevenLabs — انسانی‌ترین صدا (توصیه‌شده)**

1. به `elevenlabs.io` بروید و ثبت‌نام کنید (پلن رایگان کافی است).
2. روی عکس پروفایل (پایین سمت راست) بزنید → **API Keys**.
3. **Create API Key** → یک نام مثل `milo-narrator` → **Create**.
4. کلیدی که نشان می‌دهد را **کپی** کنید (فقط یک‌بار نشان داده می‌شود).

**گزینهٔ ۲: OpenAI**

1. به `platform.openai.com` بروید → وارد شوید.
2. از منوی چپ: **API keys** → **Create new secret key** → کپی کنید.
3. این سرویس نیاز به اعتبار دارد؛ حداقل ۵ دلار شارژ کنید
   (**Settings → Billing**).

> کلید را برای کسی نفرستید و در چت یا گیت‌هاب نگذارید. فقط در قدم ۴ استفاده می‌شود.

### قدم ۲ — بازکردن پروژه در Supabase

1. به `supabase.com/dashboard` بروید و وارد شوید.
2. پروژهٔ خود اپ را باز کنید (همان پروژه‌ای که آدرسش در
   `config/supabase.public.json` هست: `doagwkssxtxseuavrxnr`).

### قدم ۳ — ساختن تابع `narration-tts`

1. در نوار چپ، **Edge Functions** را بزنید.
2. دکمهٔ **Deploy a new function** (یا **Create a new function**) را بزنید.
3. گزینهٔ **Via Editor** را انتخاب کنید.
4. در کادر نام، **دقیقاً** این را بنویسید (کوچک و با خط تیره):

   ```
   narration-tts
   ```

5. کد نمونه‌ای که آمده را **کامل پاک کنید**.
6. فایل `supabase/functions/narration-tts/index.ts` را از مخزن باز کنید و
   **تمام محتوایش** را کپی و در ادیتور Supabase پیست کنید.
7. گزینهٔ **Verify JWT** (یا *Enforce JWT Verification*) را **خاموش** کنید.
8. **Deploy** را بزنید و تا سبز شدن وضعیت صبر کنید.

> اگر بعد از Deploy گزینهٔ JWT را ندیدید: داخل همان تابع → تب **Settings** →
> *Verify JWT* را خاموش کنید و ذخیره کنید.

### قدم ۴ — ثبت کلید به‌عنوان Secret

1. پایین نوار چپ: **Project Settings** (چرخ‌دنده).
2. **Edge Functions** → بخش **Secrets** (یا **Manage secrets**).
3. **Add new secret** را بزنید.
4. نام و مقدار را دقیقاً این‌طور وارد کنید:

   | اگر ElevenLabs گرفتید | اگر OpenAI گرفتید |
   | --- | --- |
   | Name: `ELEVENLABS_API_KEY` | Name: `OPENAI_API_KEY` |
   | Value: کلید کپی‌شده | Value: کلید کپی‌شده |

5. **Save** را بزنید.

> اختیاری برای امنیت بیشتر: یک Secret دیگر با نام `NARRATION_TTS_TOKEN` و یک
> رمز دلخواه بسازید، همان رمز را در فایل `.env` اپ هم بگذارید:
> `EXPO_PUBLIC_NARRATION_TTS_TOKEN=همان رمز`.

### قدم ۵ — آزمایش (۳۰ ثانیه)

**الف) سلامت سرویس:** این آدرس را در مرورگر باز کنید (آدرس پروژهٔ خودتان):

```
https://doagwkssxtxseuavrxnr.supabase.co/functions/v1/narration-tts?health=1
```

باید چیزی شبیه این ببینید:

```json
{"ok":true,"provider":"elevenlabs","model":"eleven_multilingual_v2","persona":"warm-female-teacher-v2","languages":["en","de","ru"]}
```

**ب) شنیدن یک جمله:**

```
https://doagwkssxtxseuavrxnr.supabase.co/functions/v1/narration-tts?lang=de&text=Guten%20Morgen!%20Wie%20geht%20es%20dir%3F
```

باید صدای زنانهٔ آلمانی پخش شود. برای انگلیسی `lang=en` و برای روسی `lang=ru`.

### قدم ۶ — دیدن نتیجه در اپ

1. اپ را باز کنید و یک درس را وارد شوید.
2. بالای درس، نوار نریتور را ببینید؛ برچسب صدا باید **«انسانی · ابری»** شود.
3. اگر هنوز نام صدای دستگاه را نشان می‌دهد: صفحه را **رفرش** کنید. اپ حداکثر هر
   ۵ دقیقه یک‌بار وضعیت سرویس را دوباره بررسی می‌کند.

## مسیر ب) با ترمینال (اگر راحت‌ترید)

```bash
# ۱) ورود و اتصال به پروژه (بار اول)
npx supabase login
npx supabase link --project-ref doagwkssxtxseuavrxnr

# ۲) انتشار تابع نریتور
npx supabase functions deploy narration-tts --no-verify-jwt

# ۳) ثبت کلید صدا (یکی از دو خط زیر)
npx supabase secrets set ELEVENLABS_API_KEY=کلید-شما
npx supabase secrets set OPENAI_API_KEY=sk-کلید-شما
```

یا همهٔ این‌ها یک‌جا:

```bash
./scripts/setup-production.sh
```

سپس همان آدرس `?health=1` را در مرورگر باز کنید.

## اگر خطا دیدید

| چه می‌بینید | معنی | راه‌حل |
| --- | --- | --- |
| `{"error":"...","code":"NARRATION_NOT_CONFIGURED"}` با کد ۵۰۳ | کلید ثبت نشده یا اسم Secret غلط است | قدم ۴؛ نام باید **دقیقاً** `ELEVENLABS_API_KEY` یا `OPENAI_API_KEY` باشد |
| کد `401` یا `Invalid JWT` | تأیید JWT روشن مانده | داخل تابع → Settings → *Verify JWT* را خاموش کنید |
| کد `502` با `TTS_FAILED` | کلید نامعتبر است یا اعتبار/سهمیه تمام شده | کلید را دوباره بسازید؛ اعتبار حساب سرویس را بررسی کنید |
| `401 NARRATION_TOKEN_INVALID` | توکن مشترک گذاشته‌اید ولی اپ آن را ندارد | همان مقدار را در `.env` بگذارید یا Secret توکن را حذف کنید |
| سلامت `ok` است ولی اپ صدای دستگاه می‌دهد | کش ۵ دقیقه‌ای اپ یا `EXPO_PUBLIC_NARRATOR_CLOUD=off` | صفحه را رفرش کنید و مقدار این متغیر را بررسی کنید |
| صفحهٔ مرورگر چیزی نشان نمی‌دهد | آدرس را بدون `&` و بدون فاصله امتحان کنید | متن را با `%20` برای فاصله و `%3F` برای `?` بنویسید |

## چقدر هزینه دارد؟

- **ElevenLabs رایگان:** حدود ۱۰٬۰۰۰ کاراکتر در ماه؛ برای شروع و تست کافی است.
- **OpenAI `gpt-4o-mini-tts`:** تقریباً چند سنت برای صدها جمله.
- **صفر هزینه برای تکرار:** هر جملهٔ تولیدشده در حافظهٔ تابع و در مرورگر کش
  می‌شود (`max-age=604800`)، پس پخش دوبارهٔ همان جمله هزینهٔ تازه ندارد.
- **خاموش‌کردن کامل ابری:** `EXPO_PUBLIC_NARRATOR_CLOUD=off` در `.env` و بیلد
  مجدد؛ از آن به بعد هیچ درخواست شبکه‌ای برای صدا زده نمی‌شود.

## چه چیزی فرستاده می‌شود؟

فقط **متن همان جملهٔ درس** (حداکثر ۳۲۰ نویسه). هیچ نام کاربر، ضبط صدا، پیام،
پیشرفت یا ترجمه‌ای ارسال نمی‌شود.

---

## خلاصهٔ چهار خطی

1. کلید از ElevenLabs (یا OpenAI) بگیر.
2. در Supabase → Edge Functions → تابع `narration-tts` را با کد مخزن بساز،
   Verify JWT را خاموش کن.
3. Secret با نام `ELEVENLABS_API_KEY` (یا `OPENAI_API_KEY`) ثبت کن.
4. آدرس `.../narration-tts?health=1` را باز کن؛ اگر `"ok":true` دیدی، تمام شد.
