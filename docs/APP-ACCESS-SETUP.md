# راه‌اندازی کنترل دسترسی کاربران

این راهنما فقط به امکان مسدودکردن یا فعال‌کردن دوبارهٔ حساب زبان‌آموز مربوط است. قابلیت اعلان/اجبار به به‌روزرسانی از اپ‌ها و پنل مدیریت حذف شده است.

## اجرای SQL در Supabase

هیچ SQL یا Edge Function از طرف ما روی Supabase اجرا نشده است.

۱. در Dashboard پروژهٔ Supabase، **SQL Editor** را باز کنید.
۲. مطمئن شوید راه‌اندازی پایه و migration کاربران مدیر، به‌ویژه `202610140002_registered_users_admin.sql`، انجام شده است.
۳. فایل `supabase/APP-ACCESS-SETUP-COPY-PASTE.sql` را کپی و اجرا کنید. این فایل فقط توابع کنترل دسترسی حساب‌ها را تنظیم می‌کند.
۴. اگر تنظیمات آپدیت قبلاً روی Supabase اجرا شده‌اند، migration جدید `202610180001_pause_app_release_management.sql` را هم اجرا کنید تا اعلان/اجبار نسخه خاموش و امکان مدیریت آن از سرور برداشته شود. این SQL را خودت در Dashboard اجرا می‌کنی؛ ما آن را اجرا نکرده‌ایم.

## استفاده در اپ مدیریت

در تب **کاربران ثبت‌شده** مدیر می‌تواند حساب زبان‌آموز را مسدود یا دوباره مجاز کند. تغییر وضعیت با اتصال دستگاه به اینترنت و تازه‌سازی بعدی اعمال می‌شود؛ گوشی آفلاین را نمی‌توان از راه دور همان لحظه قفل کرد. محتوای آموزشی، مخاطبان و گفتگوها با این قابلیت تغییر نمی‌کنند.

## نکتهٔ مربوط به migration قدیمی

برای حفظ تاریخچهٔ migrationها، migration قدیمی `202610170002_access_control_and_app_updates.sql` دست‌نخورده باقی مانده است. migration جدید، هر policy ذخیره‌شده را غیرفعال می‌کند و RPCهای مدیریتی انتشار نسخه را حذف می‌کند؛ endpoint فقط‌خواندنی باقی می‌ماند تا نسخه‌های قدیمی بتوانند policy غیرفعال را دریافت و قفل کش‌شده را پاک کنند. هیچ SQL از طرف ما اجرا نشده است.
