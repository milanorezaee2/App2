## نصب روی گوشی اندروید

1. لینک را در مرورگر گوشی باز کنید و فایل را دانلود کنید.
2. اگر پیام «نصب از منابع ناشناس» آمد، برای همان مرورگر اجازه بدهید.
3. فایل را باز کنید و **Install** را بزنید. اگر نسخهٔ قبلی نصب است، روی آن آپدیت می‌شود.
4. اگر Play Protect هشدار داد (چون با کلید دیباگ امضا شده)، «Install anyway» را بزنید.

> هر سه فایل را هم‌زمان نصب نکنید: `MiloMultilang.apk` و `MiloMultilang-Login.apk`
> بستهٔ یکسانی دارند و روی هم بازنویسی می‌شوند. یکی را انتخاب کنید.

## چه چیزی در این نسخه عوض شده

**۱) گویندهٔ شمارهٔ ۳، یک پله شفاف‌تر و یک پله آرام‌تر**

- گوینده حالا **شمارهٔ ۳** است: صدای `de+f1` (زن، روشن‌تر و جوان‌تر) با تُن بازترِ
  همان گوینده (پیچ ۶۲، دامنهٔ ۶۰) و سرعت **۱۴۸ کلمه در دقیقه** به‌جای ۱۵۸.
- «غلظت لهجه» با همان یک پله‌ای که در نمونهٔ قبلی هم استفاده شد کم شده: پیچ و دامنه
  یک پله بالا رفت و سهم انرژی بم (زیر ۳۰۰ هرتز) از **۱۰٫۸٪** در گویندهٔ قبلی به
  **۷٫۵٪** رسید؛ یعنی صدایی سبک‌تر و کمتر گرفته.
- سرعت یک پله پایین آمد (۱۵۸ ← ۱۴۸). کل گفتار درس‌ها از ۱۳٬۵۵۷ به ۱۴٬۵۷۸ ثانیه
  رسید (میانگین هر جمله از ۱٫۷۹ به ۱٫۹۲ ثانیه) — عمداً، چون خواستهٔ شما آرام‌تر
  خواندن بود.
- بستهٔ صدا با همین تنظیم از صفر ساخته شد: ۹۵ درس، ۱۹۰ کلیپ، ۷٬۵۹۲ جمله و واژه،
  ۲۲٬۰۵۰ هرتز با ۴۸ کیلوبیت. هنوز فقط یک گوینده در کل برنامه هست و هیچ گزینهٔ
  دیگری برای انتخاب صدا وجود ندارد.

**۲) آیکون صدا: اول آهسته، دوم معمولی**

- در مرحلهٔ جمله‌های اصلی، لمس **اول** آیکون بلندگو جمله را **آهسته** می‌خواند،
  لمس **دوم** **معمولی**، و به همین ترتیب یکی‌درمیان.
- دکمه‌های «آهسته» و «معمولی» زیر جمله هم همین چرخه را نگه می‌دارند و متن راهنما
  در درس و در صفحهٔ «صدای آلمانی» هم به‌روز شده است.

**۳) اصلاح‌های صدا از نسخهٔ قبل (هنوز برقرارند)**

- پرش به محل جمله فقط وقتی قبول می‌شود که موقعیت پخش واقعاً جابه‌جا شده باشد؛
  وگرنه همان جمله یک بار روی پخش‌کنندهٔ تازه تکرار می‌شود تا هرگز از اول فایل پخش
  نشود.
- شروع هر کلیپ ۶۰ هزارم ثانیه داخل سکوت قبلی است تا اولین حرف بریده نشود.
- بسته با نرخ کامل ۲۲٬۰۵۰ هرتز ساخته می‌شود؛ اگر کدک‌گذار دوباره نرخ را پایین
  بیاورد، ساخت بسته با خطا متوقف می‌شود.

**۴) صفحهٔ شروع و بقیهٔ بخش‌ها**

- نام کامل «Milo + MULTILANGUAGE» حدود ۰٫۶ ثانیهٔ آرام روی صفحه می‌ماند (۱٫۲ ثانیه
  در کل).
- محتوا، جمله‌ها، واژه‌ها و تمرین‌ها هیچ تغییری نکرده‌اند؛ انگلیسی و روسی مثل قبل‌اند.

## شنیدن صدا قبل از نصب

صفحهٔ نمونه‌ها حالا **پنج گزینه** دارد و گزینهٔ `v5` همان صدای این نسخه است
(با نشان «انتخاب‌شده»):

```
docs/voice-samples/speed/index.html
```

`v3` همان شمارهٔ ۳ با تنظیم قبلی است؛ با پخش پشت‌سرهم `v5` و `v3` تفاوت یک پله
شفاف‌تر و آرام‌تر شنیده می‌شود.

## بازسازی

```bash
git push origin arena/76e3f058-app2   # ورک‌فلوی .github/workflows/apk-quick.yml
```

سه APK را می‌سازد و در یک ریلیز منتشر می‌کند. برای تغییر گوینده یا سرعت فقط
`config/german-narrator.json` را عوض کنید و بستهٔ صدا را دوباره بسازید:

```bash
node scripts/export-german-course.cjs
python3 -m venv .venv-audio && .venv-audio/bin/pip install espeakng-loader lameenc numpy
.venv-audio/bin/python scripts/generate-german-audio.py
node scripts/generate-german-audio-assets.cjs
```
