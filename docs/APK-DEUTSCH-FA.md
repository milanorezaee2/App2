## نصب روی گوشی اندروید

1. لینک بالا را در مرورگر گوشی باز کنید و فایل را دانلود کنید.
2. اگر پیام «نصب از منابع ناشناس» آمد، برای همان مرورگر اجازه بدهید
   (Settings → Apps → مرورگر → Install unknown apps).
3. فایل را باز کنید و **Install** را بزنید. اگر نسخهٔ قبلی نصب است، روی آن آپدیت می‌شود.
4. ممکن است Play Protect هشدار بدهد؛ چون APK با کلید دیباگ امضا شده است،
   گزینهٔ «Install anyway» را انتخاب کنید.

## چه چیزی داخل این APK هست

- **صدای آلمانی داخل خود برنامه**: هر ۴۷۵۰ جمله و ۲۰۶۲ واژهٔ ۹۵ درس، به‌صورت
  ۱۹۰ فایل MP3 در بستهٔ اپ (مرحلهٔ «Verify» در CI شمارش را تأیید می‌کند).
- **پخش روان** (تغییر این نسخه): قبل از هر جمله منتظر بارگذاری فایل می‌ماند، به
  ابتدای کلیپ می‌رود، مطمئن می‌شود پوزیشن روی همان نقطه است و بعد پخش می‌کند؛
  پایان جمله هم بر اساس موقعیت واقعی پخش با ۰٫۱۲ ثانیه دنبالهٔ طبیعی است. نتیجه:
  نه پرش به جملهٔ دیگر، نه بریده‌شدن انتهای کلمات.
- بین واژه‌ها در «پخش واژه‌های این صفحه» ۲۶۰ میلی‌ثانیه فاصله هست.
- **صدای گوشی، مثل انگلیسی:** اگر در تنظیمات گوشی زبان آلمانی برای «تبدیل متن به گفتار»
  نصب باشد، جمله‌ها با همان صدا خوانده می‌شوند؛ نشانگر سربرگ درس «صدای دستگاه» می‌شود.
  اگر نباشد، نشانگر «صدای آلمانی» است و بستهٔ داخلی پخش می‌شود.
- بخش‌های انگلیسی و روسی دست‌نخورده‌اند.

## چرا حجم زیاد است

۱۵۷ مگابایت = ۵۱ مگابایت صدا + کتابخانه‌های نیتیو برای چهار معماری پردازنده
(arm64, armv7, x86, x86_64) + باندل جاوااسکریپت. اگر نسخهٔ سبک‌تر بخواهید،
می‌توان فقط `arm64-v8a` را ساخت که حجم را تقریباً نصف می‌کند.

## بازسازی همین APK

```bash
git push origin arena/76e3f058-app2      # ورکفلوی .github/workflows/apk-quick.yml
```

یا محلی، با Android SDK و JDK 17:

```bash
npm ci
npx expo prebuild --platform android --no-install
cd android && ./gradlew assembleRelease
# android/app/build/outputs/apk/release/app-release.apk
```
