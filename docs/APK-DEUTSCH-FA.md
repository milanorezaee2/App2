## نصب روی گوشی اندروید

1. لینک را در مرورگر گوشی باز کنید و فایل را دانلود کنید.
2. اگر پیام «نصب از منابع ناشناس» آمد، برای همان مرورگر اجازه بدهید.
3. فایل را باز کنید و **Install** را بزنید. اگر نسخهٔ قبلی نصب است، روی آن آپدیت می‌شود.
4. اگر Play Protect هشدار داد (چون با کلید دیباگ امضا شده)، «Install anyway» را بزنید.

> هر سه فایل را هم‌زمان نصب نکنید: `MiloMultilang.apk` و `MiloMultilang-Login.apk`
> بستهٔ یکسانی دارند و روی هم بازنویسی می‌شوند. یکی را انتخاب کنید.

## چه چیزی در این نسخه عوض شده

**۱) گویندهٔ آلمانی: همان صدای قبلی، یک پله سریع‌تر**

- همان گویندهٔ زنِ گرمِ همیشگی (`de+f3`) با سرعت **۱۶۰ کلمه در دقیقه** به‌جای ۱۴۰.
  یعنی حدود **۱۲٪ کوتاه‌تر**: کل گفتار درس‌ها از ۱۵٬۱۹۰ ثانیه به ۱۳٬۴۰۶ ثانیه رسید
  (میانگین هر جمله از ۲٫۰۰ به ۱٫۷۷ ثانیه).
- تمام ۱۹۰ کلیپ صوتی (۹۵ درس + واژه‌ها) با همین تنظیم دوباره ساخته شدند. این صدا
  داخل برنامه است، پس روی هر گوشی و بدون اینترنت **دقیقاً یکسان** شنیده می‌شود.
- حالت «خودکار» دیگر صدای گوشی را جای گویندهٔ انتخابی نمی‌گذارد؛ همان گویندهٔ انتخاب‌شده
  پخش می‌شود. اگر کلیپی در دسترس نبود، صدای آلمانی گوشی جای آن را می‌گیرد تا درس
  هرگز بی‌صدا نماند. گزینهٔ «همیشه صدای گوشی» هم در صفحهٔ صدا هنوز کار می‌کند.

**۲) دکمهٔ بلندگو در درس آلمانی**

- لمس اول: **معمولی** (همان سرعت تندتر).
- لمس دوم روی همان جمله: **آهسته**.
- لمس سوم دوباره معمولی، و به همین ترتیب. دکمه‌های «آهسته» و «معمولی» زیر جمله هم
  سر جای خودشان هستند و این چرخه را هم‌زمان نگه می‌دارند.

**۳) یکدست‌شدن با قالب روسی (از نسخهٔ قبل)**

- صفحهٔ شروع درس در هر سه زبان یکسان است: آیکون → «موقعیت واقعی» → عنوان → موقعیت →
  «در پایان این درس می‌توانید…» → نکتهٔ زبان به فارسی.
- کارت سطح و ریل سطح‌ها در انگلیسی و آلمانی همان قالب روسی را دارند (شماره از صفر،
  START، یک واژه‌نامهٔ سطح).

**۴) محتوای روسی ساده و گویندهٔ روسی خانم (از نسخهٔ قبل)**

- روسی دوباره ۶۹ درس و ۵۵۲ جملهٔ کوتاه است.
- صدای روسی زنانه ترجیح داده می‌شود و اگر گوشی فقط صدای مرد داشته باشد، درس بی‌صدا نمی‌شود.

**۵) سرعت باز شدن اپ و صدای خوش‌آمد (از نسخهٔ قبل)**

- باز شدن زیر ۰٫۷ ثانیه؛ کاربر تأییدشده در قطعی اینترنت بیرون انداخته نمی‌شود؛
  خوش‌آمد انگلیسی با صدای طبیعی گوشی خوانده می‌شود.

## بازسازی

```bash
git push origin arena/76e3f058-app2   # ورک‌فلوی .github/workflows/apk-quick.yml
```

سه APK را می‌سازد و در یک ریلیز منتشر می‌کند. برای تغییر گوینده یا سرعت فقط
`config/german-narrator.json` را عوض کنید و بستهٔ صدا را دوباره بسازید:

```bash
node scripts/export-german-course.cjs
python3 -m venv .venv-audio && .venv-audio/bin/pip install espeakng-loader lameenc numpy
.venv-audio/bin/python scripts/generate-german-audio.py
```
