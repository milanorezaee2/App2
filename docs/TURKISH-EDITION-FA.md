# نسخهٔ دوم اپ: ترکی استانبولی به جای روسی

این سند توضیح می‌دهد چطور یک مخزن و یک کد، **دو نسخهٔ مستقل** می‌سازد:

| نسخه | پرچم ساخت | زبان‌ها | ورودی |
| --- | --- | --- | --- |
| نسخهٔ اصلی (دست‌نخورده) | بدون پرچم | انگلیسی، آلمانی، **روسی** | `/languages` |
| نسخهٔ ترکی | `EXPO_PUBLIC_TURKISH_EDITION=true` | انگلیسی، آلمانی، **ترکی استانبولی** | `/learn/tr` |

هر دو نسخه از همان کد رابط، همان طراحی، همان ورود/ثبت‌نام و همان موتور پیشرفت
استفاده می‌کنند؛ تنها چیزی که عوض می‌شود «کاتالوگ زبان» و مسیر ورودی است.
دورهٔ روسی در نسخهٔ ترکی از فهرست زبان‌ها حذف می‌شود و مسیرهای `/learn/ru`
به صفحهٔ زبان‌ها هدایت می‌شوند؛ دورهٔ ترکی هم در نسخهٔ اصلی نمایش داده نمی‌شود.

## اجرا و ساخت

```bash
# نسخهٔ اصلی (روسی)
npm run dev:web            # یا: npm run build:web && npm run serve:web

# نسخهٔ دوم (ترکی) با ورود فعال
npm run dev:turkish                                   # ساخت و اجرای توسعه
npm run build:web:turkish && npm run preview:turkish   # خروجی در dist-turkish روی پورت 8082

# بررسی دادهٔ دوره و پرچم‌های نسخه
npm run validate:turkish
```

`app.config.js` در حالت ترکی، نام و شناسهٔ مستقل می‌سازد:

- نام: `MiloMultiLanguage Turkish`
- slug: `milomultilanguage-turkish` (یا `milomultilanguage-turkish-login` وقتی ورود فعال است)
- پکیج اندروید/آی‌او‌اس: `com.devicecontrol.miloturkish`
- scheme: `miloturkish`
- `extra.turkishEdition: true`

برای بیلد اندروید همین پرچم‌ها را به EAS بدهید:

```bash
EXPO_PUBLIC_TURKISH_EDITION=true EXPO_PUBLIC_LEARNER_LOGIN=true npx eas build -p android --profile production
```

## دورهٔ ترکی

- ۲۸ درس جمله‌محور در چهار سطح: Foundation (۸)، Survival (۸)، Everyday (۸)، Communication (۴)
- ۲۲۴ جمله با معنی فارسی، تلفظ تقریبی فارسی، واژهٔ کلیدی و الگوی جمله
- برای هر درس: دیالوگ نقش‌آفرینی، دو پرسش خودآموز، نکتهٔ فارسی و جریان ۹مرحله‌ای
  (موقعیت، جمله‌ها، شنیدن، سایه‌خوانی، ساخت جمله، واژگان، دستور در کاربرد،
  مکالمه، مرور فاصله‌دار)
- فایل‌ها:
  - `lib/languages/turkish.ts` — سطح‌ها، ترتیب درس‌ها، `turkishProgress`
  - `lib/languages/turkishFoundationLessons.ts` … `turkishCommunicationLessons.ts` — محتوا
  - `lib/languages/turkishStudyState.ts` — جلسهٔ ناتمام درس (کلید `turkish_lesson_sessions_v1`)
  - `components/Turkish*.tsx` — خانه، درس، کتابخانه، مرور، جمله‌سازی، دیالوگ و نوار پایین
  - `app/learn/tr/*` — مسیرهای وب/اپ

پیشرفت ترکی در `sentence_course_progress_tr_v1` ذخیره می‌شود و با مسیر انگلیسی،
آلمانی و روسی ترکیب نمی‌شود. مرور فاصله‌دار از همان موتور مشترک می‌آید.

## صدا

برای ترکی هنوز فایل صوتی تأییدشدهٔ CDN ساخته نشده است؛ بنابراین:

- دکمه‌های پخش روی گویندهٔ ترکی دستگاه (`tr-TR`) کار می‌کنند و اگر صدای ترکی روی
  دستگاه نصب نباشد، پیام روشن نمایش داده می‌شود.
- نوار نریتور ابری به‌صورت پیش‌فرض مخفی است تا انتظار نادرست ایجاد نکند. بعد از
  انتشار صدا، با `EXPO_PUBLIC_TURKISH_CLOUD_NARRATOR=true` برمی‌گردد.
- Edge Function `narration-tts` حالا `lang=tr` را هم می‌پذیرد (متغیرهای
  `OPENAI_TTS_VOICE_TR` یا `ELEVENLABS_VOICE_TR`) تا پس از deploy بتوان صدای
  انسانی ترکی را جایگزین کرد.

## محدودیت‌های آگاهانه

- محتوای ۲۲۴ جملهٔ ترکی هنوز بازبینی مستقل مدرس ترکی را ندارد؛ شمار سطح‌ها
  برچسب برنامه‌ریزی داخلی است و گواهی CEFR نیست.
- کارگاه تلفظ مستقل ترکی وجود ندارد؛ تب «تلفظ» به درس «صداها و حروف ویژه»
  (`tr-l1-sounds`) می‌رود.
- دورهٔ روسی در نسخهٔ ترکی حذف نشده، فقط از فهرست و مسیرها کنار گذاشته شده است
  تا دو نسخه بدون شاخهٔ جداگانه ساخته شوند.
