# نسخهٔ دوم اپ: ترکی استانبولی به جای روسی

این سند توضیح می‌دهد چطور یک مخزن و یک کد، **دو نسخهٔ مستقل** می‌سازد:

| نسخه | پرچم ساخت | زبان‌ها | ورودی |
| --- | --- | --- | --- |
| نسخهٔ اصلی (دست‌نخورده) | بدون پرچم | انگلیسی، آلمانی، **روسی** | `/languages` |
| نسخهٔ ترکی | `EXPO_PUBLIC_TURKISH_EDITION=true` | انگلیسی، آلمانی، **ترکی استانبولی** | `/learn/tr` |

هر دو نسخه از همان کد رابط، همان طراحی، همان ورود/ثبت‌نام و همان موتور پیشرفت
استفاده می‌کنند؛ تنها چیزی که عوض می‌شود «کاتالوگ زبان» و مسیر ورودی است.
دورهٔ روسی در نسخهٔ ترکی از فهرست زبان‌ها حذف می‌شود و مسیرهای `/learn/ru`
به صفحهٔ زبان‌ها هدایت می‌شوند؛ دورهٔ ترکی هم در نسخهٔ اصلی نمایش داده نمی‌شود.

## اجرا و ساخت

```bash
# نسخهٔ اصلی (روسی)
npm run dev:web            # یا: npm run build:web && npm run serve:web

# نسخهٔ دوم (ترکی) با ورود فعال
npm run dev:turkish                                   # ساخت و اجرای توسعه
npm run build:web:turkish && npm run preview:turkish   # خروجی در dist-turkish روی پورت 8082

# بررسی دادهٔ دوره و پرچم‌های نسخه
npm run validate:turkish
```

`app.config.js` در حالت ترکی، نام و شناسهٔ مستقل می‌سازد:

- نام: `MiloMultiLanguage Turkish`
- slug: `milomultilanguage-turkish` (یا `milomultilanguage-turkish-login` وقتی ورود فعال است)
- پکیج اندروید/آی‌او‌اس: `com.devicecontrol.miloturkish`
- scheme: `miloturkish`
- `extra.turkishEdition: true`

برای بیلد اندروید همین پرچم‌ها را به EAS بدهید:

```bash
EXPO_PUBLIC_TURKISH_EDITION=true EXPO_PUBLIC_LEARNER_LOGIN=true npx eas build -p android --profile production
```

## دورهٔ ترکی

- **۶۶ درس و ۵۲۸ جمله** در چهار پله: A1 Foundation (۱۴ درس)، A1 Survival (۲۰ موضوع برنامه در ۲۴ درس)، Everyday · A2 (۲۴ درس) و Communication · B1 (۴ درس).
- ترتیب ۱۴ موضوع Foundation و ۲۰ موضوع Survival دقیقاً مطابق فهرست جدید است؛ تمام ۲۰ درس Foundation پیشین و ۸ درس Survival قبلی حفظ شده‌اند. شش درس قبلیِ خارج از فهرست ۱۴موضوعی Foundation، بدون تغییر متن و جمله‌ها به جایگاه متناسب در Survival منتقل شده‌اند؛ چهار درس تکمیلیِ هم‌موضوع نیز کنار موضوع مرتبط قرار گرفته‌اند.
- هر درس ۸ جمله با معنی فارسی، تلفظ تقریبی فارسی، واژهٔ کلیدی و الگوی جمله دارد؛ همچنین دیالوگ نقش‌آفرینی، دو پرسش خودآموز، نکتهٔ فارسی و جریان ۹مرحله‌ای.

| مسیر | موضوع/درس | جمله |
| --- | ---: | ---: |
| A1 Foundation | ۱۴ | ۱۱۲ |
| A1 Survival | ۲۰ موضوع اصلی + ۴ درس تکمیلی (۲۴ درس) | ۱۹۲ |
| Everyday · A2 | ۲۴ | ۱۹۲ |
| Communication · B1 | ۴ | ۳۲ |
| **جمع** | **۶۶ درس** | **۵۲۸** |

- فایل‌ها:
  - `lib/languages/turkish.ts` — سطح‌ها، سرفصل‌ها، ترتیب دوره و `turkishProgress`؛ شناسهٔ درس‌های جابه‌جا‌شده ثابت مانده است.
  - `lib/languages/turkishFoundationLessons.ts` و `turkishFoundationLessonsB.ts` — تمام ۲۰ درس اولیهٔ A1؛ ۱۴ درس نخستِ سرفصل در Foundation و ۶ درس پایانی در جایگاه متناسب Survival نمایش داده می‌شوند.
  - `lib/languages/turkishSurvivalLessons.ts` — ۸ درس موجود کافه، رستوران، خرید، مسیر، زمان، حمل‌ونقل، هتل و سلامت.
  - `lib/languages/turkishSurvivalLessonsB.ts` — ۱۰ درس تازه برای موضوع‌های اجتماعی، گردشگری، بلیت، بازار، درخواست کمک، کار/تحصیل، آب‌وهوا، تلفن، دعوت و توانایی.
  - `lib/languages/turkishA2LessonsA.ts` (درس ۱–۱۲ A2)، `turkishA2LessonsB.ts` (درس ۱۳–۲۴ A2) و `turkishCommunicationLessons.ts` — محتوای سطح‌های بعدی.
  - `lib/languages/turkishStudyState.ts` — جلسهٔ ناتمام درس (کلید `turkish_lesson_sessions_v1`).
  - `components/Turkish*.tsx` — خانه، درس، کتابخانه، مرور، جمله‌سازی، دیالوگ و نوار پایین.
  - `app/learn/tr/*` — مسیرهای وب/اپ.

پیشرفت ترکی در `sentence_course_progress_tr_v1` ذخیره می‌شود و با مسیر انگلیسی، آلمانی و روسی ترکیب نمی‌شود. مرور فاصله‌دار از همان موتور مشترک می‌آید.

برای اینکه هیچ محتوای قبلی حذف نشود، Survival بیست موضوع بالا را در **۲۰ درس اصلی** پوشش می‌دهد و چهار درس قدیمی تکمیلی را نیز در جایگاه مرتبط نگه می‌دارد: رستوران کنار موضوع غذا، حرکت کنار مسیر‌یابی، زمان کنار برنامهٔ روزانه و حروف ربط پس از موضوع آینده. در نتیجه این پله ۲۴ درس دارد. شناسهٔ درس‌های پیشین تغییر نکرده تا پیشرفت ذخیره‌شدهٔ زبان‌آموز حفظ شود. ۱۴ درس Foundation هرکدام ۸ جمله دارند؛ Survival شامل ۱۹۲ جمله در ۲۴ درس است.

شناسهٔ درس‌های A2 `tr-l2-01-…` تا `tr-l2-24-…` است و شناسهٔ جمله‌هایشان `tr3-01` تا `tr3-192` است تا با شناسه‌های Survival تداخل نکند.
اعتبارسنجی ترتیب دقیق ۲۴ عنوان A2 و شمار سطح‌ها را `۱۴|۲۴|۲۴|۴` بررسی می‌کند؛ کل دوره ۶۶ درس و ۵۲۸ جمله دارد.

## صدا

برای ترکی هنوز فایل صوتی تأییدشدهٔ CDN ساخته نشده است؛ بنابراین:

- دکمه‌های پخش روی گویندهٔ ترکی دستگاه (`tr-TR`) کار می‌کنند و اگر صدای ترکی روی
  دستگاه نصب نباشد، پیام روشن نمایش داده می‌شود.
- نوار نریتور ابری به‌صورت پیش‌فرض مخفی است تا انتظار نادرست ایجاد نکند. بعد از
  انتشار صدا، با `EXPO_PUBLIC_TURKISH_CLOUD_NARRATOR=true` برمی‌گردد.
- Edge Function `narration-tts` حالا `lang=tr` را هم می‌پذیرد (متغیرهای
  `OPENAI_TTS_VOICE_TR` یا `ELEVENLABS_VOICE_TR`) تا پس از deploy بتوان صدای
  انسانی ترکی را جایگزین کرد.

## محدودیت‌های آگاهانه

- محتوای ۲۲۴ جملهٔ ترکی هنوز بازبینی مستقل مدرس ترکی را ندارد؛ شمار سطح‌ها
  برچسب برنامه‌ریزی داخلی است و گواهی CEFR نیست.
- کارگاه تلفظ مستقل ترکی (`/learn/tr/pronunciation`) شش حرف ویژهٔ ç/ş/ğ/ı/ö/ü را با
  واژه‌های واقعی دوره و پخش صدا تمرین می‌کند و از ترتیب ۲۰درس بیرون است.
- دورهٔ روسی در نسخهٔ ترکی حذف نشده، فقط از فهرست و مسیرها کنار گذاشته شده است
  تا دو نسخه بدون شاخهٔ جداگانه ساخته شوند.
