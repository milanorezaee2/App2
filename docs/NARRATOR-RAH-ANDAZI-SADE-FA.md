# راهنمای خیلی ساده — صدای قشنگ برای درس‌ها 🎧

## ماجرا چیه؟

الان درس‌های ما با «صدای دستگاه» خونده می‌شن. مثل صدای رباتِ گوشی.
ما می‌خوایم یه **خانم واقعی** جمله‌ها رو بخونه؛ گرم و قشنگ.

اون خانم واقعی توی اینترنت زندگی می‌کنه.
اسم جایی که توش کار می‌کنه **Supabase** هست.
تو فقط باید ۳ تا کار کوچیک بکنی. من قدم‌به‌قدم می‌گم. 🙂

---

## کار اول: یه کلید بگیر 🔑

کلید یعنی «اجازه‌نامه». مثل کلید خونه.

1. برو به سایت **elevenlabs.io**
2. ثبت‌نام کن (رایگانه).
3. پایین صفحه، روی **عکس خودت** بزن.
4. **API Keys** رو بزن.
5. **Create API Key** رو بزن. یه اسم بده، مثلاً `milo`.
6. یه نوشتهٔ طولانی بهت می‌ده. **کپی کن.**
   ⚠️ این کلید دیگه نشون داده نمی‌شه. یه جا بذارش که گم نشه.

---

## کار دوم: یه اتاق برای اون خانم بساز 🚪

1. برو به **supabase.com/dashboard**
2. وارد شو.
3. پروژهٔ اپ خودمون رو باز کن.
4. سمت چپ، **Edge Functions** رو بزن.
5. **Deploy a new function** رو بزن.
6. **Via Editor** رو انتخاب کن.
7. اسمش رو **دقیقاً** این بنویس:

   ```
   narration-tts
   ```

8. اون کدهایی که خودش نوشته رو **پاک کن**.
9. حالا فایل `supabase/functions/narration-tts/index.ts` رو از پروژه باز کن،
   **همه‌ش** رو کپی کن و بچسبون اون‌جا.
10. یه کلید کوچیک هست به اسم **Verify JWT** → **خاموشش کن.**
11. **Deploy** رو بزن. صبر کن سبز بشه.

---

## کار سوم: کلید رو بده بهش 🗝️

1. پایین سمت چپ، **Project Settings** (چرخ‌دنده) رو بزن.
2. **Edge Functions** رو بزن.
3. **Secrets** رو بزن.
4. **Add new secret** رو بزن.
5. دو تا کادر می‌بینی:

   - کادر اول (اسم): بنویس `ELEVENLABS_API_KEY`
   - کادر دوم (مقدار): اون کلیدی که کپی کردی رو بچسبون.

6. **Save** رو بزن. ✅

---

## حالا امتحانش کن 🧪

این آدرس رو تو مرورگر باز کن:

```
https://doagwkssxtxseuavrxnr.supabase.co/functions/v1/narration-tts?health=1
```

اگه اینو دیدی، یعنی درست شده:

```json
{"ok":true}
```

بعد برو تو اپ، یه درس رو باز کن.
اگه بالای درس نوشته بود **«انسانی · ابری»**، یعنی خانم واقعی اومده. 🎉

---

## اگه نشد چی؟

| چی می‌بینی | یعنی چی | چیکار کن |
| --- | --- | --- |
| `NARRATION_NOT_CONFIGURED` | کلید یادش رفته | کار سوم رو دوباره انجام بده |
| `401` یا `Invalid JWT` | اون کلید کوچیک روشن مونده | برو تو تابع → Settings → خاموشش کن |
| `502` | کلید خرابه یا اعتبار تموم شده | کلید تازه بگیر |
| همه‌چی `ok` ولی اپ هنوز صدای ربات می‌ده | اپ هنوز خبر نداره | صفحه رو رفرش کن (۵ دقیقه صبر کن) |

---

## سه سؤال که شاید بپرسی

**پول می‌خواد؟**
نه، اولش رایگانه. حدود ۱۰ هزار حرف در ماه مجانیه. برای شروع کلی زیاد.

**کاربرا چی می‌فرستن؟**
فقط خودِ جملهٔ درس. هیچ اسمی، هیچ صدایی، هیچ چیزی از کاربر نمی‌ره.

**اگه اینترنت قطع بشه؟**
مشکلی نیست. همون صدای دستگاه می‌خونه. درس هیچ‌وقت ساکت نمی‌مونه.

1. از ElevenLabs یه کلید بگیر.
2. تو Supabase یه اتاق به اسم `narration-tts` بساز و کدش رو بذار.
3. کلید رو بذار تو Secrets. تمام! 🎊
