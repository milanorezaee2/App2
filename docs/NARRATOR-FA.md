# نریتور حرفه‌ای درس‌ها — انگلیسی، آلمانی، روسی

این سند دقیقاً توضیح می‌دهد چه چیزی اضافه شده، چرا این روش انتخاب شده، چطور
روشن/خاموش می‌شود و چطور می‌توان صدای انسانی ابری را فعال کرد.

## چه اتفاقی افتاده

در هر سه مسیر آموزشی، یک **نریتور خانم، گرم و رسا** اضافه شده است. به‌محض
ورود به درس، همان جمله‌ای که روی صفحه است یک‌بار خوانده می‌شود و با رفتن به
جملهٔ بعد، نریتور خودکار جملهٔ تازه را می‌خواند. آیکون‌های صوتی قبلی هم دست‌نخورده
باقی مانده‌اند و حالا واقعاً صدا پخش می‌کنند.

مسیرها:

| زبان | صفحه | محل نوار نریتور | رنگ |
| --- | --- | --- | --- |
| انگلیسی | `app/course/lesson.tsx` | بالای محتوای درس | آبی `#1769D2` |
| آلمانی | `app/learn/[language]/lesson.tsx` | بالای محتوای درس | آبی `#1769D2` |
| روسی | `components/RussianLesson.tsx` | بالای محتوای درس | بنفش `#8175F2` |

ساختار درس، مرحله‌ها، ذخیرهٔ پیشرفت، جلسهٔ قابل ادامه و همهٔ دکمه‌های قبلی هیچ
تغییری نکرده‌اند. نریتور فقط یک لایهٔ صوتی افزودنی است.

## دو لایهٔ صدا (بهترین حالت + پشتیبان)

1. **نریتور ابری انسانی (اولویت اول):** اگر Edge Function با نام
   `narration-tts` روی همان پروژهٔ Supabase منتشر شده باشد و کلید
   `OPENAI_API_KEY` ثبت شده باشد، جمله با مدل گفتاری `gpt-4o-mini-tts` و
   صدای زنانهٔ طبیعی خوانده می‌شود. برای هر زبان یک پرسونا تعریف شده است:
   «معلم زبانِ خانم، آرام، شفاف، گرم و با لحن دوستانه؛ فقط جمله را می‌خواند و
   چیزی اضافه نمی‌کند.»
2. **صدای نورال دستگاه (پشتیبان خودکار):** اگر تابع منتشر نشده باشد، اینترنت
   قطع باشد یا درخواست شکست بخورد، همان لحظه بهترین صدای زنانهٔ نصب‌شده روی
   دستگاه/مرورگر انتخاب می‌شود. درس هرگز بی‌صدا نمی‌ماند.

انتخاب صدای دستگاه در `lib/narrator/voiceCast.ts` انجام می‌شود: صداهای زنانهٔ
شناخته‌شده (Aria، Jenny، Ava، Samantha، Anna، Katja، Hedda، Svetlana،
Dariya، Milena و …) امتیاز مثبت می‌گیرند، صداهای مردانه (Conrad، Killian،
Yuri، Dmitry و …) کنار گذاشته می‌شوند و صداهای Natural/Neural/Online بر
صداهای Compact و رباتیک اولویت دارند. سرعت و زیروبمی هم برای هر زبان تنظیم
شده است تا خواندن «معلم‌گونه» باشد، نه خواناتر ماشینی.

## راه‌اندازی صدای انسانی ابری (اختیاری، یک‌بار)

```bash
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase functions deploy narration-tts --no-verify-jwt
npx supabase secrets set OPENAI_API_KEY=sk-...
```

یا فقط `./scripts/setup-production.sh` را اجرا کنید؛ تابع هم منتشر می‌شود.

بررسی سلامت:

```bash
curl "https://YOUR_PROJECT.supabase.co/functions/v1/narration-tts?health=1"
# {"ok":true,"provider":"openai","model":"gpt-4o-mini-tts", ...}
```

تنظیمات اختیاری:

| متغیر | کاربرد | پیش‌فرض |
| --- | --- | --- |
| `OPENAI_TTS_MODEL` | مدل گفتاری | `gpt-4o-mini-tts` |
| `OPENAI_TTS_VOICE_EN` / `_DE` / `_RU` | صدای هر زبان | `nova` / `coral` / `coral` |
| `NARRATION_TTS_TOKEN` | توکن مشترک ضد سوءاستفاده | بدون توکن |

اگر توکن گذاشتید، همان مقدار را در `EXPO_PUBLIC_NARRATION_TTS_TOKEN` هم بگذارید.

## کنترل‌های کاربر

نوار نریتور چهار کنترل دارد:

- **پخش/توقف موقت** — خواندن همان جمله.
- **خودکار** — روشن/خاموشِ خواندن خودکار. انتخاب روی همان دستگاه ذخیره می‌شود.
- **آهسته / معمولی** — سرعت نریتور.
- **تکرار** — خواندن دوبارهٔ جمله بدون تغییر مرحله.

اگر مرورگر پخش خودکار را مسدود کند (سیاست Safari و بعضی نسخه‌های Chrome)، نوار
یک پیام کوتاه و یک دکمهٔ «برای شروع نریتور یک‌بار بزنید» نشان می‌دهد؛ بعد از یک
لمس، پخش ادامه پیدا می‌کند.

## هم‌زیستی با دکمه‌های صوتی قبلی

همهٔ آیکون‌های صدا در سه مسیر از یک کانال صوتی واحد استفاده می‌کنند. هر بار که
دکمهٔ صوتی درس زده شود، نریتور ساکت می‌شود و برعکس؛ بنابراین دو صدا هرگز روی هم
نمی‌افتند. نریتور خودکار هم اگر ببیند صدای دیگری در حال پخش است، همان جمله را
تکرار نمی‌کند.

## حریم خصوصی و هزینه

- فقط **متن همان جملهٔ درس** به تابع فرستاده می‌شود؛ هیچ دادهٔ کاربر، ضبط صدا،
  پیام یا ترجمه‌ای ارسال نمی‌شود.
- طول متن به ۳۲۰ نویسه محدود است، سرعت به بازهٔ ۰٫۶ تا ۱٫۲ و زبان به
  `en`/`de`/`ru`.
- پاسخ‌ها هم در حافظهٔ خود تابع (۱۶۰ جملهٔ آخر) و هم با هدر
  `Cache-Control: max-age=604800` در مرورگر کش می‌شوند؛ تکرار یک جمله هزینهٔ
  دوباره ندارد.
- برای خاموش‌کردن کامل مسیر ابری بدون تغییر کد:
  `EXPO_PUBLIC_NARRATOR_CLOUD=off` (فقط صدای دستگاه، بدون هیچ درخواست شبکه‌ای).

## فایل‌های تازه

```text
lib/narrator/voiceCast.ts        انتخاب صدای زنانه + تنفس و سرعت هر زبان
lib/narrator/cloudNarrator.ts    کشف، کش و پخش صدای ابری + بازکردن قفل پخش مرورگر
lib/narrator/engine.ts           موتور مشترک نریتور و تنظیمات ذخیره‌شده
lib/narrator/useLessonNarrator.ts قلاب اتصال هر درس به موتور
components/LessonNarrator.tsx    نوار نریتور
supabase/functions/narration-tts/index.ts  نریتور ابری (اختیاری)
```

تغییرهای موجود در فایل‌های قدیمی فقط این‌هاست: روشن‌شدن کلید `NARRATION_ENABLED`
در `lib/narration.ts`، یک قلاب توقف برای هماهنگی صدا، و یک خط `<LessonNarrator />`
در هر سه صفحهٔ درس.

## بازبینی

```bash
npm run typecheck
npm run build:web
npm run dev:web
```

در مرورگر، درس انگلیسی/آلمانی/روسی را باز کنید؛ نوار نریتور باید بالای محتوا
دیده شود و جملهٔ اول خودکار خوانده شود. اگر از Edge استفاده کنید صدای
«Microsoft … Natural» و اگر تابع ابری فعال باشد برچسب «انسانی · ابری» نمایش
داده می‌شود.
