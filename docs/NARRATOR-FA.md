# نریتور حرفه‌ای درس‌ها

این سند توضیح می‌دهد نریتور خودکار درس‌ها چطور صدا را انتخاب می‌کند، چرا صدای
انسانی به یک سرویس ابری نیاز دارد، و چطور در یک مرحله آن را فعال کنید.

## چه اتفاقی افتاده

در هر سه مسیر آموزشی، هنگام ورود به درس، جملهٔ روی صفحه خودکار خوانده می‌شود و
با رفتن به جملهٔ بعد، نریتور جملهٔ تازه را می‌خواند. نوار نریتور بالای محتوای درس
چهار کنترل دارد: پخش/توقف، تکرار، آهسته/معمولی و کلید «خودکار» (روی دستگاه
ذخیره می‌شود).

| زبان | صفحه | رنگ نوار |
| --- | --- | --- |
| انگلیسی | `app/course/lesson.tsx` | آبی `#1769D2` |
| آلمانی | `app/learn/[language]/lesson.tsx` | آبی `#1769D2` |
| روسی | `components/RussianLesson.tsx` | بنفش `#8175F2` |

ساختار درس، مرحله‌ها، ذخیرهٔ پیشرفت، جلسهٔ قابل ادامه و همهٔ دکمه‌های قبلی هیچ
تغییری نکرده‌اند. نریتور فقط یک لایهٔ صوتی افزودنی است.

## چرا صدا ماشینی شنیده می‌شد و چه چیزی اصلاح شد

سه ایراد واقعی در مسیر صدای دستگاه پیدا و رفع شد:

1. **انتخاب صدای پیش‌فرض به‌جای صدای درست.** مرورگرها فهرست صداها را با تأخیر
   منتشر می‌کنند. وقتی فهرست خالی خوانده می‌شد، جمله با صدای پیش‌فرض سیستم (گاهی
   فارسی یا انگلیسی) خوانده می‌شد. اکنون پیش از انتخاب صدا تا ۷۰۰ میلی‌ثانیه
   منتظر می‌مانیم (`lib/speechLanguage.ts`).
2. **جملهٔ تکه‌تکه و منقطع.** جمله‌های کوتاه درس قبلاً به قطعه‌های ۱۵۰ نویسه‌ای
   تقسیم می‌شدند و بین قطعه‌ها مکث مصنوعی می‌افتاد. اکنون هر جملهٔ درس (تا ۳۲۰
   نویسه) **در یک نَفَس و یک utterance** خوانده می‌شود؛ فقط متن‌های بلندتر و
   واقعاً چندجمله‌ای تقسیم می‌شوند و مکث هم ۷۰ میلی‌ثانیه است.
3. **سرعت و زیروبمی مصنوعی.** `rate` و `pitch` دستکاری‌شده (۰٫۹۳ و ۱٫۰۴)
   روی بعضی موتورها لرزش و لحن رباتیک می‌سازد. اکنون سرعت طبیعی (۱ برای
   انگلیسی، ۰٫۹۷ آلمانی، ۰٫۹۶ روسی) و pitch برابر ۱ است؛ حالت «آهسته» هم
   سرعت را ۲۰٪ کم می‌کند، نه اینکه جمله را بشکند.

همچنین امتیازدهی صدا بازنویسی شد: صداهای **زنانهٔ Natural/Neural/Online/Google**
اولویت دارند، صداهای مردانه کنار گذاشته می‌شوند و موتورهای قدیمی SAPI
(David/Zira/Mark) امتیاز منفی می‌گیرند.

> نکته مهم: بهترین صدای ممکن روی دستگاه، باز هم صدای TTS است. برای صدای
> «۱۰۰٪ انسانی» باید جمله‌ها از یک سرویس عصبی ابری Synthesis شوند؛ این همان
> لایهٔ دومی است که در ادامه فعال می‌شود.

## سه لایهٔ صدا

1. **ElevenLabs** (انسانی‌ترین): اگر `ELEVENLABS_API_KEY` ثبت شود، مدل
   `eleven_multilingual_v2` با صدای زنانهٔ گرم (پیش‌فرض Sarah) جمله را می‌خواند.
2. **OpenAI** (`gpt-4o-mini-tts`): اگر `OPENAI_API_KEY` ثبت شود؛ با دستور
   (instructions) «معلم زبان خانم، گفتار پیوسته و طبیعی، لحن گرم و آرام، بدون
   خواندن کلمه‌به‌کلمه».
3. **صدای نورال دستگاه**: پشتیبان خودکار در نبود اینترنت یا کلید؛ درس هرگز
   بی‌صدا نمی‌ماند.

هر سه لایه از یک persona استفاده می‌کنند (`warm-female-teacher-v2`)، بنابراین
صدای درس در همهٔ دستگاه‌ها ثابت می‌ماند.

## فعال‌سازی صدای انسانی (یک‌بار)

```bash
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase functions deploy narration-tts --no-verify-jwt
npx supabase secrets set ELEVENLABS_API_KEY=...     # انسانی‌ترین (اختیاری)
# یا
npx supabase secrets set OPENAI_API_KEY=sk-...
```

یا فقط `./scripts/setup-production.sh` را اجرا کنید؛ تابع هم منتشر می‌شود.

اگر به ترمینال دسترسی ندارید، از داشبورد Supabase:
`Edge Functions → New function → narration-tts` و محتوای
`supabase/functions/narration-tts/index.ts` را کپی کنید؛ سپس
`Project Settings → Edge Functions → Secrets` کلید را ثبت کنید.

بررسی سلامت:

```bash
curl "https://YOUR_PROJECT.supabase.co/functions/v1/narration-tts?health=1"
# {"ok":true,"provider":"elevenlabs","model":"eleven_multilingual_v2", ...}
```

تنظیمات اختیاری:

| متغیر | کاربرد | پیش‌فرض |
| --- | --- | --- |
| `NARRATION_PROVIDER` | انتخاب اجباری `elevenlabs` یا `openai` | خودکار |
| `OPENAI_TTS_MODEL` | مدل گفتاری OpenAI | `gpt-4o-mini-tts` |
| `OPENAI_TTS_VOICE_EN` / `_DE` / `_RU` | صدای هر زبان | `nova` / `coral` / `coral` |
| `ELEVENLABS_MODEL` | مدل ElevenLabs | `eleven_multilingual_v2` |
| `ELEVENLABS_VOICE_EN` / `_DE` / `_RU` | شناسهٔ صدا | Sarah |
| `NARRATION_TTS_TOKEN` | توکن مشترک ضد سوءاستفاده | بدون توکن |

اگر توکن گذاشتید، همان مقدار را در `EXPO_PUBLIC_NARRATION_TTS_TOKEN` هم بگذارید.

## رفتار کاربر و دسترس‌پذیری

- **خودکار**: با ورود به درس و با تغییر جمله، یک‌بار می‌خواند؛ هیچ‌وقت روی صدای
  دکمه‌های دیگر درس حرف نمی‌زند.
- **آهسته**: صدا با سرعت طبیعی ساخته می‌شود و پخش ۲۰٪ کندتر و بدون تغییر pitch
  انجام می‌شود؛ نتیجه طبیعی می‌ماند.
- اگر مرورگر پخش خودکار را مسدود کند، نوار یک پیام کوتاه و دکمهٔ «یک‌بار بزنید»
  نشان می‌دهد و بعد از یک لمس ادامه می‌دهد.
- هر کنترل، برچسب دسترس‌پذیری فارسی و وضعیت `switch`/`busy` دارد.

## حریم خصوصی و هزینه

- فقط **متن همان جملهٔ درس** به سرویس فرستاده می‌شود؛ هیچ دادهٔ کاربر، ضبط صدا،
  پیام یا ترجمه‌ای ارسال نمی‌شود.
- طول متن به ۳۲۰ نویسه، زبان به `en`/`de`/`ru` محدود است.
- پاسخ‌ها در حافظهٔ تابع (۱۶۰ جملهٔ آخر) و با هدر
  `Cache-Control: max-age=604800` در مرورگر کش می‌شوند؛ تکرار یک جمله هزینهٔ
  دوباره ندارد.
- جملهٔ جاری پیش از خواندن از قبل pre-fetch می‌شود تا پخش فوری و پیوسته باشد.
- خاموش‌کردن کامل مسیر ابری: `EXPO_PUBLIC_NARRATOR_CLOUD=off` (فقط صدای دستگاه،
  بدون هیچ درخواست شبکه‌ای).

## فایل‌ها

```text
lib/narrator/voiceCast.ts        انتخاب صدای زنانه، سرعت طبیعی و تقسیم متن
lib/narrator/cloudNarrator.ts    کشف، pre-fetch، کش و پخش صدای ابری
lib/narrator/engine.ts           موتور مشترک نریتور و تنظیمات ذخیره‌شده
lib/narrator/useLessonNarrator.ts قلاب اتصال هر درس به موتور
components/LessonNarrator.tsx    نوار نریتور
supabase/functions/narration-tts/index.ts  نریتور ابری (ElevenLabs/OpenAI)
scripts/verify-narrator.mjs      تست انتخاب صدا، پیوستگی و مسیر ابری
```

تغییرهای فایل‌های قدیمی: روشن‌شدن `NARRATION_ENABLED` در `lib/narration.ts`، یک
قلاب توقف برای هماهنگی صدا، انتظار برای فهرست صداها در `lib/speechLanguage.ts`
(رفع باگ انتخاب صدای پیش‌فرض) و یک خط `<LessonNarrator />` در هر سه صفحهٔ درس.

## بازبینی

```bash
npm run typecheck
npm run validate:narrator   # ۲۹ بررسی: صدا، پیوستگی، قطع تمیز، مسیر ابری
npm run build:web
npm run dev:web
```

در مرورگر، درس را باز کنید؛ نوار نریتور باید بالای محتوا باشد و جملهٔ اول خودکار
خوانده شود. برچسب صدا در نوار نشان می‌دهد کدام لایه فعال است: «انسانی · ابری»
برای سرویس ابری، یا نام صدای دستگاه (مثلاً Aria / Google / Samantha).
