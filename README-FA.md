# Language Journey — آموزش چندزبان

ورودی فعلی اپ، انتخاب انگلیسی، آلمانی یا روسی است. مسیر فعال آلمانی جمله‌محور **۹۵ درس و ۴٬۷۵۰ جملهٔ نمونه** در چهار باند آموزشی داخلی دارد: Pre-A1 برابر ۲۰ درس/۱٬۰۰۰ جمله/۳۹۶ مدخل واژگانی یکتا، A1 برابر ۲۵/۱٬۲۵۰/۵۸۷، A2 برابر ۲۵/۱٬۲۵۰/۷۱۶ و B1 برابر ۲۵/۱٬۲۵۰/۷۳۴. در A2 و B1 پنج نمونهٔ اصلی هر درس حفظ شده و ۴۵ نمونهٔ تازه به همان ترتیب افزوده شده است؛ شمار واژگان با یکتاسازی مدخل‌های همان سطح محاسبه می‌شود و عبارت‌های چندواژه‌ای را هم شامل است. گزارش جاری گسترش A2 و B1 در `docs/GERMAN-A2-B1-EXPANSION.md` و گزارش‌های جداگانهٔ A1 و گسترش‌های پیشین در `docs/GERMAN-A1-EXPANSION.md` و `docs/GERMAN-A2-EXPANSION.md`/`docs/GERMAN-B1-EXPANSION.md` آمده‌اند. نمونه‌های تازه ترجمهٔ فارسی، راهنمای تقریبی تلفظ، واژگان و نکتهٔ آموزشی سطح‌متناسب دارند. سطح‌بندی داخلی گواهی یا اعتبارسنجی رسمی CEFR نیست. محتوای قدیمی آلمانی از مسیرهای فعال کنار گذاشته و برای سازگاری داخلی نگه داشته شده است. روسی یک مسیر جمله‌محور مستقل با نقشهٔ پنج‌سطحی، ۱۴ درس و ۸۴ جمله در دو پلهٔ آغازین دارد؛ Foundation اکنون هفت درس و ۴۲ جمله دارد. مسیر مکمل انگلیسی Foundation (۴ واحد) و A1 (۲۰ واحد) را با تمرین چهارمهارته و سنجش محلی دربر می‌گیرد؛ این نتیجه گواهی رسمی CEFR نیست. جزئیات انگلیسی در `docs/ENGLISH-BEGINNER-A1-COMPLETION-FA.md`، گزارش جاری Survival در `docs/ENGLISH-SURVIVAL-50-EXAMPLES-REPORT-FA.md` و گزارش‌های مراحل پیشین در `docs/SURVIVAL-COMPLETION-REPORT-FA.md` و `docs/EVERYDAY-ENGLISH-EXPANSION-REPORT-FA.md` آمده‌اند.

## نریتور حرفه‌ای درس‌ها

در هر سه مسیر انگلیسی، آلمانی و روسی یک نریتور خانم، گرم و رسا اضافه شده است.
به‌محض ورود به درس، جملهٔ روی صفحه خودکار خوانده می‌شود و با رفتن به جملهٔ بعد،
نریتور همان جملهٔ تازه را می‌خواند. نوار نریتور بالای محتوای درس، پخش/توقف،
تکرار، سرعت آهسته/معمولی و کلید «خودکار» را در اختیار می‌گذارد و انتخاب کاربر
روی همان دستگاه ذخیره می‌شود.

صدا سه لایه دارد: با ثبت `ELEVENLABS_API_KEY` (انسانی‌ترین) یا `OPENAI_API_KEY`
روی Edge Function با نام `narration-tts`، جمله با صدای انسانی و طبیعی خوانده
می‌شود؛ در غیر این صورت بهترین صدای نورال زنانهٔ نصب‌شده روی دستگاه/مرورگر
انتخاب می‌شود تا درس هرگز بی‌صدا نماند. هر جمله در یک نَفَس و با سرعت طبیعی خوانده
می‌شود (بدون تقسیم مصنوعی و بدون تغییر pitch)، و جملهٔ جاری پیش از پخش آماده
می‌شود. راه‌اندازی، حریم خصوصی، هزینه و بازبینی در `docs/NARRATOR-FA.md` آمده است.

```bash
npm run validate:narrator   # انتخاب صدای زنانه، خواندن خودکار و قطع‌شدن تمیز
```

## اجرای محلی

```bash
npm install
npm run typecheck
npm run validate:content   # ۱۷۴ درس، ۳٬۸۶۲ جمله و پوشش ۵۰۴ واژه
npm run validate:logic     # تست منطق درس‌ها، مرور فاصله‌دار و ذخیره پیشرفت
npm run validate:russian   # محتوای آغازین روسی، جریان ۹مرحله‌ای و جداسازی
npm run validate:russian-architecture  # نقشهٔ A1–B2، چرخهٔ جمله‌محور و شواهد محلی
npm run validate:english-supplement  # ۲۴ واحد، پاسخ‌ها و نگهداشت سابقه
npm run validate:backup            # ادغام ایمن بکاپ انگلیسی و حفظ پیش‌نویس محلی
npm run validate:personal-sync     # OTP/RLS و ادغام پیشرفت ابری
npm run dev -- --web
```

`validate:logic` ماژول‌های واقعی اپ را در Node اجرا می‌کند (با stub کردن حافظه و Supabase)
و هم مسیر بومی (AsyncStorage) و هم مسیر وب (localStorage) را بررسی می‌کند؛ اگر از .env
قالب استفاده شده باشد یا کلیدها خالی باشند، همان‌جا هشدار می‌دهد. `validate:english-supplement`
ساختار دوره، پاسخ‌ها، ذخیرهٔ قبلی و دو سنجش پایانی را بررسی می‌کند.

## راه‌اندازی Backend با یک دستور

> اگر به ترمینال دسترسی ندارید، کل همین کار را می‌توانید فقط با مرورگر انجام دهید:
> راهنمای کامل در `docs/RAH-ANDAZI-BEDOON-TERMINAL.md` و فایل آماده برای
> کپی/پیست در SQL Editor در `supabase/SETUP-COPY-PASTE-ONCE.sql` است.
> هر دو مسیر (اسکریپت و داشبورد) بک‌اند یکسانی می‌سازند.

نیازی به نصب سراسری Supabase CLI نیست. ابتدا (فقط بار اول) وارد حساب شوید و پروژه را Link کنید:

```bash
npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF
```

`YOUR_PROJECT_REF` همان بخش اول آدرس پروژه است: `https://YOUR_PROJECT_REF.supabase.co`.
سپس راه‌اندازی کامل با یک دستور انجام می‌شود:

```bash
./scripts/setup-production.sh
```

اسکریپت از `npx supabase` استفاده می‌کند، migration را اجرا و چهار Edge Function موردنیاز را منتشر می‌کند.

## ساخت APK مستقل

شناسه Android این برنامه `com.devicecontrol.companion` است و با برنامه‌های دیگر تداخل ندارد.

```bash
npm install -g eas-cli
eas login
eas build --platform android --profile production
```

پروفایل production در `eas.json` خروجی APK می‌سازد، onboarding واقعی را فعال نگه می‌دارد و از امضای مدیریت‌شده EAS استفاده می‌کند.
